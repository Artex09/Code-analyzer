    How this reads a repository
    
    
    
      
    
        
    scoring
    
        
    Each file is matched against sink rules (dangerous operations), source rules (places
        untrusted input enters) and entrypoint rules (routes, handlers, CLI, jobs). A file holding
        both a source and a sink is boosted; vendored, generated and test paths are damped. Path
        names carry their own weight, so auth/, admin/,
        payment/ and legacy/ surface earlier.
    
        
    Scores saturate: 0-15 minimal, 15-35 low, 35-55 medium, 55-75 high, 75+ critical.
        A hit is a lead, never proof — mark what you confirm, dismiss what you rule out, and
        the report orders itself around your calls.
